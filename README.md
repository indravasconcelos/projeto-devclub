## Sobre o projeto

O projeto consiste em uma pagina institucional completa e profissional para o DevClub, uma plataforma de ensino de programação. A página foi desenvolvida com foco em:

- **Experiência do usuário** — navegação intuitiva e conteúdo bem organizado
- **Design moderno** — visual premium com paleta de cores coesa e tipografia refinada
- **Animações** — transições suaves, scroll reveal, efeitos de parallax e canvas interativo
- **Responsividade** — Mobile First, adaptado para todos os tamanhos de tela
- **Performance** — código otimizado sem dependências externas
- **Acessibilidade** — semântica HTML, atributos ARIA e navegação por teclado

---

## Funcionalidades

- **Hero Section** com vídeo em background e overlay gradiente
- **Navbar** fixa com efeito blur ao rolar e menu mobile hamburger
- **Seção Jornada** com cards sticky e barra de progresso lateral
- **Seção Aprender** com abas interativas e visualizações temáticas (código, React, IA, etc.)
- **Além do Código** — grid de benefícios com ícones e descrições
- **Seção Mentores** com visualização de rede neural em canvas (galáxia neural)
- **Comunidade** — mural de fotos com animação de entrada e carrossel de depoimentos
- **Seção Mercado** — faixas salariais, empresas parceiras e FAQ interativo (accordion)
- **CTA Final** — chamada para ação com garantia de 7 dias
- **Footer** completo com links e informações

## Responsividade

O projeto foi desenvolvido utilizando a abordagem **Mobile First** e é totalmente adaptado para:

- Smartphones (320px+)
- Tablets (768px+)
- Notebooks (1024px+)
- Monitores Desktop (1200px+)

---

## Performance

- Código **organizado e comentado** por seções
- **CSS otimizado** com Custom Properties e seletores eficientes
- **JavaScript vanilla** sem dependências externas
- Imagens com **lazy loading** (`loading="lazy"`)
- **Canvas API** utilizado de forma eficiente com `requestAnimationFrame`
- **Intersection Observer** para animações sob demanda (sem consumo desnecessário de recursos)
- Boa experiência do usuário em qualquer dispositivo
